운영자 로그인

Cloudflare 관리자 비밀번호로 로그인합니다. 한 번 로그인하면 이 브라우저와 이 주소에서 7일 동안 유지됩니다. 다른 주소(미리보기 주소·운영 도메인)에서는 따로 로그인해야 합니다.

도서·판매·영상 관리

도서 등록·수정, PDF 교체, 가격·그로블 주소, 유튜브 샘플강의 링크를 여기서 관리합니다. 저장과 PDF 교체는 즉시 반영되며, 도서를 추가할 때마다 코드 수정이나 재배포를 하지 않습니다.

운영 정보를 불러오고 있습니다.

운영 도서 목록
